# Button

Compact 32px controls with an 8px radius. White is the one primary; grey carries every other action.

**Consumer provides:** a sentence-case label of one to four words.

**Tokens:** `primary`, `on-primary`, `primary-hover`, `fill-secondary`, `fill-secondary-hover`, `shadow-ring`, `radius-md`, `radius-xs`

One primary per view. Add `gl-btn--lg` (44px) where the primary touch target matters.
