Hand-inked SVG doodles: 1px `ink` (#000) line with a turbulence wobble filter, flat fills in `powder`, `powder-50`, paper, light gray and solid ink, inked black offsets for depth. Every file has a fixed ink; nothing uses currentColor.

- `sparkle-outline` (paper fill) / `sparkle-powder` — the AI/insight sign; twinkle them.
- `hexagon`, `squircle-ink`, `squircle-paper` — confetti; spin them.
- `burst` — white spiky backdrop behind a celebratory object.
- `donut`, `bar-card`, `line-chart-card` — floating data props; bob or sway them, tilt 8–15°.
- `connector` — dashed arrow with nodes for diagrams.
- `spot-report` — a complete spot illustration (report sheet + magnifier + satellites) for feature cards and product panes.
- `scribble-ellipse-*`, `scribble-underline-*` — word marks in ink (paper/fog grounds), paper (powder/ink grounds) or powder (ink grounds). In live text prefer the `data-ik-scribble` hook so it draws on.
