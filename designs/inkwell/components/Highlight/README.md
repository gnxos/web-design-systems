# Highlight

A powder box with a sketchy ink border behind a phrase — the closing-CTA way to make a question pop.

**Consumer provides:** a short phrase (2–4 words) inside `<span class="ik-highlight">`. Call `Inkwell.init()` (or `Inkwell.ensureFilter()`) once so the border gets its hand-drawn wobble.

- Use on paper or fog only (on powder it vanishes); at most one per page, typically the second line of a centred CTA headline.
- Text stays `on-powder` black at headline weight.
