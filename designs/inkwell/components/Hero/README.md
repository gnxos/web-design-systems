# Hero

A centred opener: kicker, headline, lead and two actions over this system's own art.

**Consumer provides:** A headline under 40 characters, one lead sentence, two actions.

- Root class `ik-herox` (parts use `ik-herox__…`, variants `--…`).
- Art is decorative; text sits over a scrim when the art is dark.
- Headline uses the system's display style.
- Styled from Inkwell's own tokens: ground `surface`, panels `surface-fog`, ink `ink`, secondary text `ink (68% mix)`, accent `powder`, lines `line / line-strong`, radii `radius-l / radius-xl / radius-m`.
- Buttons inside it are this system's own (`ik-btn`); motion uses its timing and easing tokens and stops under `prefers-reduced-motion`.
