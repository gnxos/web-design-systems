# Stat

A big powder numeral with a short label, set on an ink block — proof, not decoration.

**Consumer provides:** the number (numerals and a `+`, `%`, `x` suffix only) and a 1–3 word label.

- Markup: `.ik-stat > span.ik-stat__num + span.ik-stat__label` inside a `data-theme="dark"` block; place 2–3 in a row with ~80px gaps under a headline.
- On paper use `ink` for the numeral instead of powder (powder on white fails contrast).
