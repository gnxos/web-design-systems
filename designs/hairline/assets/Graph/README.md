# Graph assets

Original SVGs drawn for Hairline. Fixed inks are the light-theme token values, noted per file.

- `work-graph.svg` — 960×540 hero still: four callout cards (white, 1px #e7e7e7, radius 10, soft slate shadow) around a central purple orb, joined by 1px ink (#0d0d0d) right-angle wires with white node discs and one coral (#f06a6a) live node. Text is shown as grey bars so you can lay real copy over it or use it as a placeholder. The live, animated version is the WorkGraph component.
- `orb-blue.svg`, `orb-coral.svg`, `orb-green.svg`, `orb-purple.svg` — 160×160 glow orbs (#4786ff, #ff584a, #22b455, #df5dff) with a white highlight top-left, a thin white rim and a blurred halo below, on a transparent ground. The CSS version is `hl-orb`.
- `pastel-labels.svg` — 640×200 reference sheet: the six highlight-label fills (mint, highlighter, orchid, sky, blush, lilac) with ink text bars, plus the inline marker behind words in a line of text.
