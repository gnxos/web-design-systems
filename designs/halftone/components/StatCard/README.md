# StatCard

A card that leads with one big regular-weight number and a mint mono tag naming the outcome; a pink variant stacks glass bubbles.

**Consumer provides:** the number with sign/unit, the outcome (2–4 words), an optional one-line headline.

- `ht-card` (surface) or `ht-card--white` with `span.ht-stat` + `span.ht-tag--mint`.
- Pink variant: `ht-card--pink` with `ht-bubble`s ("<b>+24%</b> Win rate"), stacked and cropped by the card's bottom edge.
