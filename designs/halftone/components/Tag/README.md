# Tag

Mono uppercase chips: lavender default, mint metric tags, butter highlights, ink name chips, outline role chips and smoked glass chips with icons.

**Consumer provides:** 1–4 words; optional 13px icon.

- `ht-tag` lavender · `--mint` the outcome under a stat · `--butter` notices · `--ink` + `--line` for name + role under a quote · `--smoke` capability chips on photos and glass.
- Text is always ink (or white on smoke) — never pink.
