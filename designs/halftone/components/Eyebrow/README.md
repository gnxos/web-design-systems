# Eyebrow

The section kicker: a "/" marker and a short UPPERCASE label on up to two lines, with a pink shimmer sweeping through the letters.

**Consumer provides:** 2–5 words.

- Markup: `p.ht-eyebrow > span`. Sits top-left of a section header, opposite the `heading-1`.
- One shimmering eyebrow per view; others can drop the animation (`style="animation:none"` on the span).
