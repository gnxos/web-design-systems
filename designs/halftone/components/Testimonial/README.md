# Testimonial

A white card pairing a big slate metric with a quote and two mono chips for the person's name and role.

**Consumer provides:** metric + one-word label, quote (≤ 3 lines), name, role.

- Markup: `div.ht-card.ht-card--white` (grid: stat column + quote column). Metric in `stat` coloured `ink-secondary`; label in mono `tag` under it.
- Use real quotes with permission; never invent attributions.
