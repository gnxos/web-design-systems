# NewsTicker

A glass pill with a "NEWS" label, a continuously scrolling headline, and an arrow disc linking to the story.

**Consumer provides:** 1–3 short headlines and a link.

- Markup: `div.ht-ticker > span.ht-ticker__label + div.ht-ticker__window > div.ht-ticker__track > span*` + `a.ht-btn__disc`; `Halftone.ticker()` doubles the track for a seamless loop.
- Only over photos or dark grounds; one per page, in the hero.
