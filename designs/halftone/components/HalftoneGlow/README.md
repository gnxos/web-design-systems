# HalftoneGlow

A dark panel with a square grid of pink dots swelling toward the centre — the backdrop for floating portrait tiles; plus the pixel-mosaic glow used for footers.

**Consumer provides:** the panel content (headline, copy, 3–5 portrait tiles), or the footer content over the pixel glow.

- Halftone: `<canvas data-ht-halftone>` absolutely filling an `ht-card--ink` (radius-xl), content above it.
- Pixel glow: Assets → Graphics → `pixel-glow.svg` as a cover background on black, hot corner bottom-left.
