# Button

Pill buttons with mono uppercase labels: pink primary, white, ink and ghost variants, plus an arrow-circle CTA.

**Consumer provides:** a 1–3 word label; for the arrow variant, the link target.

| Variant | Classes | When |
| --- | --- | --- |
| Pink | `ht-btn ht-btn--pink` | The single primary action in view. Label in `on-pink` (ink). |
| White | `ht-btn ht-btn--white` | Secondary on dark/photo grounds ("SIGN IN"). |
| Ink | `ht-btn ht-btn--ink` | Primary on light grounds when pink is already used nearby. |
| Ghost | `ht-btn ht-btn--ghost` | Tertiary on white. |
| Arrow | add `ht-btn--arrow` + `span.ht-btn__disc` | Section CTAs ("GET STARTED →"). |
| Small | add `ht-btn--sm` | Inside the nav. |

- Never more than one pink button per view. Never icons on the left.
