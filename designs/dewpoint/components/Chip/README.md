# Chip

A 28px pill label for categories, states and meta, 12.5px 500 weight.

**Consumer provides:** one to two words; never a sentence.

- Neutral `dp-chip`: `surface-container-high` with `on-surface` text (16:1).
- Outline `dp-chip--outline`: `outline-strong` edge (3.4:1) on transparent.
- Accent `dp-chip--accent`: `accent-text` fill with `on-accent-text` label (5.5:1 light, 8.8:1 dark).
- Dark `dp-chip--dark`: `primary` fill; leading 14px icon allowed.
- `dp-chip--in` rises 6px and fades in over 200ms (`ease-out-quart`), the source's chip entrance. Off under reduced motion.
- State is carried by a word, never by colour alone.
