# Patterns

Single-ink patterns, ink `#121317` (an `<img>` cannot inherit `currentColor`; in the Dark theme apply `filter: invert(1)`).

- `dot-drift.svg` 1600×520, jittered dots fading toward the bottom. Section background.
- `dot-grid.svg` 560×560, regular 28px grid of 1.6px dots at 45% opacity. Tile or repeat.
- `hairline-ruler.svg` 800×40, tick marks every 16px with a taller tick every 80px. Separators and captions.
