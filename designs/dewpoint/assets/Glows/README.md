# Glows

Art for 36px media tiles. All 1000×1000, multi-colour, blur done with SVG filters (no external references).

- `ring-azure.svg` black to navy with a blurred azure ring. Put a white title in the centre.
- `ring-ember.svg` near-black red with a blurred coral/amber pill outline.
- `halo-pastel.svg` pale grey-blue with a grey card and blurred blue, magenta and gold glows. Light tiles; also the frame for the window placeholder.
- `field-azure.svg` flat azure to deep-blue gradient. White 24px+ titles only.
- `field-midnight.svg` deep blue to black gradient.

Use as `<img class="dp-tile__art">` inside `.dp-tile`. See `../../imagery.md`.
