# Fields

Fleck fields: hundreds of tiny rounded dashes pointing away from a clear centre, hue sweeping blue, violet, magenta, coral, amber, gold. Transparent background; place on `surface` or `night`.

- `fleck-field-light.svg` 1600×900. Hero ground in the Light theme. Dust dots are ink.
- `fleck-field-dark.svg` 1600×900. Same layout with light dust dots and brighter flecks, for the Dark theme.
- `fleck-field-corner.svg` 1200×1200. Square version for a banner or tile corner.
- `fleck-band-dark.svg` 1600×220. Even scatter for the footer band over `night`.

Multi-colour, so no ink to name. Use as `<img>` with `alt=""`. See `../../imagery.md`.
