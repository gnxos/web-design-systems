# Doodles

Loose hand-drawn marks, 3px round-capped strokes, no fill. Ink is `#121317` (fixed; invert for Dark with `filter: invert(1)`).

- `loop.svg` 240×160, a looping line ending in an arrowhead.
- `squiggle.svg` 240×40, a wavy underline.
- `burst.svg` 160×160, ten alternating-length rays.
- `brackets.svg` 200×120, two curly brackets with a dot.

Use one per section at most, beside a heading, never over text.
