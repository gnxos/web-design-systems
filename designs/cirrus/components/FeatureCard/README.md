# FeatureCard

A tall card (528px wide, 40px radius) with sky art above and a frosted content panel below.

**Consumer provides:** a title of 4–7 words, one sentence, one Trailing-dot button label, and sky art.

- Two cards per row with a 24px gap; one column under 767px.
- Panel: 48px padding, `backdrop-filter: blur(50px)` over 1% white, a 62% bottom `photo-scrim` gradient so white text clears 4.5:1 on any art.
- Title 39/1.3 weight 500 white; text 16/24 white.
- Whole card is the link; hover only changes the button (white fill, black label).
