# InsightCard

A white card (16px radius, `shadow-ui-lg`) that sits on a gradient field inside a product mock-up: name, meta, a coloured status line, reason tags and a 12-week square strip.

**Consumer provides:** a name, one meta line, one status sentence (risk or opportunity), one to three reason tags, a 12-length series, and a count sentence.

- Status colour is `danger-text` (5.0:1 on white) or `success-text` (5.0:1); tags use `danger-soft` / `success-soft` with the same text colours (4.6:1). Always include the words ("Open issue", "Expansion"), never colour alone.
- Squares are 10px, 3px gap; empty squares `surface-container-higher`.
- Max width 300px. Overlap cards by about 60px in mock-ups and fan them down and to the right.
- These cards illustrate a product. Use invented company names only.
