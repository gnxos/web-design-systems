# Testimonial

A two-column quote on light ground: a 219px square portrait (24px radius) and the text beside it.

**Consumer provides:** a portrait (or `assets/Panels/avatar-*.svg`), a company name set as plain text, a quote under 200 characters, a name and a role.

- Grid 219px / 1fr, 40px gap. Stacks under 767px.
- Quote 20/30 `on-surface`, curly quotes, max 34em. Name 20/30. Role 16/24 `on-surface-variant` (5.0:1 on white).
- Company mark is plain 600-weight type; never a customer logo.
- Portraits are original or illustrative; use real photos only with consent.
