# Skies

Large atmospheric backgrounds, multi-colour, no ink to name. Use as `<img>` with `alt=""` under a scrim and frosted panel.

- `sky-day.svg` 1600×900. Deep blue to pale haze with soft cumulus. Hero field.
- `sky-card.svg` 1000×1000. Square crop for tall feature cards.
- `sky-dusk.svg` 1600×900. Navy, violet and peach horizon with peach clouds.
- `night-streaks.svg` 1600×600. Near-black navy with diagonal light streaks. Banner.
- `mist-mesh.svg` 1200×800. Pale blue-lilac mesh behind mock-up cards.
