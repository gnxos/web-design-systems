# Button

Square, mono, uppercase. Small L-shaped marks sit on the four corners.

**Consumer provides:** a verb-first label of one to three words, typed in sentence case (CSS sets the caps).

**Tokens:** `primary`, `primary-hover`, `on-primary`, `primary-safe`, `accent-edge`, `shadow-bevel`, `button-label`

White on `primary` is 2.3:1. Use `df-btn--safe` where contrast must pass.
