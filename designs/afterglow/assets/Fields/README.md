Grainy gradient fields and a node-graph render, all 1200×800 SVG unless noted. Each field is a linear base + two or three very soft colour masses + fractal-noise grain (overlay). Use them as image backplates for exports, slides and social cards; in UI prefer the CSS tiles in `bundle.css` (`ag-tile--ember`, `--teal`, `--warm`, `--sand`, `ag-hero`).

- `field-dusk` — hero only: teal haze, one ember glow right of centre, dark vignette. Text: paper 90%, bottom-left.
- `field-ember` — ember → coral. Headlines and numbers only (paper text is 3.9:1).
- `field-tide` — teal → slate. Paper text.
- `field-warm` — sand → coral → ember. Charcoal text.
- `field-sand` — near-flat sand. Charcoal text.
- `grain-tile` — 160×160 white-on-transparent noise; tile it with `mix-blend-mode: overlay` at 0.6 opacity over any colour.
- `node-graph` — 960×560 dark panel: a light hub card with eight series-coloured node chips (sample labels).
