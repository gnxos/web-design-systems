# StatTile

A tile whose content is one big pixel-face number with a short label — on sand, ember or a dark panel.

**Consumer provides:** the number (numerals + suffix: "+", "x", "%", "B"), a 2–6 word label, an optional mono comparison line at the top ("$4.10 vs $5.02").

- Numbers in `stat-xl` (72px) for a lone hero number, `stat` (44px) in grids; `ag-pixel` class.
- One number per tile; never a chart and a stat in the same tile.
