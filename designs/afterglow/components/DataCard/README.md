# DataCard

A small translucent key/value card that floats over a gradient field (the hero's fact box).

**Consumer provides:** 3–5 label/value pairs with short values; an optional caption under it.

- Markup: `dl.ag-kv > (dt + dd)*`; labels left in 74% paper, values right-aligned.
- Only over gradient fields or images; on plain panels use a table instead.
